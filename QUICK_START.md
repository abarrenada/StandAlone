# StandAlone Carton Label Printing Module — Quick Start Guide

## Equipment Support

This module is designed for **Nuovofina sorters** (primary production equipment). The architecture also supports:

- **Nuovofina Sorters** ✅ (Current implementation — production-ready)
- **System Sorters** ⚠️ (Adaptable with configuration switch)
- **SATI Sorters** ⚠️ (Adaptable with configuration switch)
- **Private Label Systems** ❌ (Different architecture — future phase)

For complete technical analysis of all PLC interface types, message formats, and implementation guidance, see:
👉 **PLC_INTERFACE_COMPLETE_ANALYSIS.md**

## Configuration Files Created

### Flag Files (Root Directory)
These files enable/disable features on a per-line basis:

- **DoesManStk** — Enables "Primary Item" field in startup form
  - Contains: Line number `01` (one per line)
  - Effect: Shows Primary Item TextBox + async description lookup

- **DoesTwoPrims** — Enables "2nd Primary Item" field (requires DoesManStk)
  - When present: Shows both Primary Item and 2nd Primary Item fields
  - Description lookups work for both fields

### Sample Data Files (data/ Directory)

#### itemdet.csv (43-column format)
- **Sample Items**:
  - `FL9036MOD1P4` → FL90-WHITE | 3 X 6 X 0.31 IN | FINISH LINE
  - `LMN-999` → CLASSIC WHITE | 12 X 12 IN | STANDARD SERIES
  - `ABC-12345` → NATURAL CLAY | 6 X 6 X 0.38 IN | ABC COLLECTION
  - `SKU-001` → WHITE | 8 X 8 IN | BASIC
  - `SKU-002` → BEIGE | 4 X 4 X 0.25 IN | MOSAIC PLUS

#### stackers01.csv
- 3 sample stacker records (Line 1, Stacks 1-3)

#### boxes01.csv
- 5 sample box records for browse panel testing

## How to Test

### Test Primary Item Lookup

1. **Run the application** (F5 in Visual Studio)
2. **Enter Startup Information**:
   - Shift: 1 (or any 1-9)
   - Inspector: TEST
   - Label Size: (select any available)
   - **Primary Item**: Enter `FL9036MOD1P4`
   - Press Tab or Enter
3. **Expected Result**:
   - Description appears below field:
     ```
     FL90-WHITE | 3 X 6 X 0.31 IN | FINISH LINE
     ```
   - Text color: Light Green (success)

### Test Lookup Failure

1. **Primary Item**: Enter `INVALID123`
2. Press Tab or Enter
3. **Expected Result**:
   ```
   ⚠ Item 'INVALID123' not found in item master
   ```
   - Text color: Salmon (error)

### Test Browse Panel

1. Click **Begin** after startup
2. **Browse Panel** should show:
   - Last 5 boxes from boxes01.csv
   - Item descriptions resolved from stackers01.csv + itemdet.csv
   - All F-key buttons available (F1, F3, F4, F6, F7, F8)

## Configuration for Production

When ready for production:

1. **Replace sample CSV files** with real data from SAP/ERP:
   - `itemdet.csv` — Export from Progress itemdet + itemhdr tables (43 columns)
   - `mitemdet.csv` — Mexico items (same 43 columns)
   - `boxes01.csv`, `stackers01.csv` — Auto-generated by PLC

2. **Adjust line number** in sample files:
   - Update `DoesManStk` file with actual line numbers (01, 02, 03, etc.)
   - Update CSV filenames: `boxes01.csv` → `boxes{NN}.csv`, etc.

3. **Configure Settings** (⚙ button on startup form):
   - CSV Directory: `C:\LabelPrint\data\`
   - Production Line: 01 (or actual line number)
   - PLC Connection: Serial Port or IP
   - Label Output: NiceLabel Xml, SerialPort, or HttpPost

## Additional Equipment Types

### System Sorters (dtplc060.p)

If you have **System Sorter** equipment instead of Nuovofina:

1. Message format is identical (65 characters)
2. Only Format 1 input supported (no PLC Format 2)
3. Item parsing would need to be disabled
4. **Effort to support:** 2-4 hours (configuration-based)

See **PLC_INTERFACE_COMPLETE_ANALYSIS.md** → "Part 4.2: System Sorters Implementation"

### SATI Sorters (dtplc043.p)

If you have **SATI/MIX/ROTOMIX** equipment:

1. Message format is identical (65 characters)
2. Stack number not parsed (always "??")
3. Stacker lookup by item instead of stack
4. **Effort to support:** 1-2 hours (configuration-based)

See **PLC_INTERFACE_COMPLETE_ANALYSIS.md** → "Part 4.3: SATI Implementation"

### Private Label Systems (dtplc045.p)

**Not currently supported** — requires reverse-flow architecture (sends TO PLC, not receives FROM PLC).

See **PLC_INTERFACE_COMPLETE_ANALYSIS.md** → "Part 4.4: Private Label Implementation"

## Message Format Reference

### Nuovofina Format 2 (PLC Input)

```
Position:  0-1        2-31           32-61              62-65
Content:  [Stack]   [Filler]      [Item Info]        [Metadata]
Example:  " 1"   [31 spaces]  "FL9036MOD1P4       "  "2R1"
          ^^                    ^^^^^^^^^^^^^^
          Stack                 Item Number
```

Total length: **65 characters** (fixed)

### System Sorter Format 1 (Manual)

```
stacker#(99), reprint(X), shift(9), Inspec(XX)
Example: " 1,Y,1,AB"
```

No item parsing — uses existing stacker record.

### SATI Format 2 (Item-based, no stack)

```
Position:  0-1        2-31           32-61              62-65
Content:  "??"     [Filler]      [Item Info]        [Metadata]
Example:  "??"   [31 spaces]  "FL9036MOD1P4       "  "2R1"
          ^^^
          Stack always unknown
```

Lookup by item, not stack.
